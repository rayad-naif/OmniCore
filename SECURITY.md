# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the maintainers through the
repository's private security reporting channel. If that channel is unavailable,
contact the project owner directly rather than opening a public issue.

Include a clear description, affected components or versions, reproduction
steps or a proof of concept, impact, and any suggested mitigation. Do not
include production credentials, access tokens, or customer data.

We will acknowledge reports as soon as practical, investigate the issue, and
coordinate a fix and disclosure timeline with the reporter. Please allow time
for remediation before sharing details publicly.
